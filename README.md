# My Vacuum Hunts My Cable

One original line roasting a gadget I use every day — my robot vacuum —
for the bounty
[One-Line Roast: The Gadget You Use Every Day](https://make.fun/competitions/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610).

`main.py` (Python 3.13, standard library only) writes the roast to
`/output/entry.txt`. It is deterministic: every run writes byte-identical
output.

## The roast

> My robot vacuum has mapped my flat to the centimetre, yet every morning it still drags my charging cable home like a trophy: "I found the snake again."

151 characters, one line, first-person, one concrete gadget and one
specific funny flaw, with a short kicker at the end.
